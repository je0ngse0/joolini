# 주리니

거래대금이 많은 종목부터 애널리스트, 기관 수급, 가격 모멘텀을 함께 살펴보는
로컬 주식 추천 웹사이트입니다.

기본 실행은 외부 데이터 계약 없이 제품 동작을 검증하기 위한 **모의 데이터 MVP**입니다.
한국투자증권 Open API 키가 있으면 실제 현재가 조회 모드로 전환할 수 있습니다.

## 실행

```bash
GRADLE_USER_HOME=/private/tmp/joolini-gradle ./gradlew bootRun
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 제공 기능

- 한국·미국 종목 통합 및 시장별 보기
- 원화 환산 거래대금 내림차순 기본 정렬
- 추천·관망·비추천 필터와 종목 검색
- 2초 주기의 모의 실시간 시세 및 SSE 갱신
- 추천 점수와 애널리스트·수급·모멘텀 근거 상세 보기

실제 공개 서비스로 전환하려면 시세와 애널리스트 데이터의 상업적 재배포 계약이 필요합니다.

## 한국투자증권 실제 가격 연결

한국투자증권 Open API의 App Key와 App Secret을 발급받은 뒤, 실제 키를 파일이나
명령 기록에 커밋하지 말고 현재 터미널의 환경변수로 설정합니다.

```bash
cp .env.example .env
```

복사한 `.env`에 `KIS_APP_KEY`, `KIS_APP_SECRET`, `KIS_ENABLED=true`를 입력한 뒤
`./run-local.sh`로 실행합니다. `.env`는 Git에서 제외되며 화면이나 API 응답에도
키가 노출되지 않습니다.

실제 가격 모드는 국내·미국 관심 종목의 현재가, 등락률, 누적 거래량과 거래대금을
한국투자증권 REST API에서 기본 15초마다 갱신합니다. 호출 주기는
`KIS_POLL_RATE_MS`로 조정할 수 있습니다.

종목별 요청은 기본 0.7초 간격으로 순차 처리합니다. KIS가 초당 거래건수 초과
오류를 반환하면 2초 대기 후 한 번만 자동 재시도합니다. 계정별 제한이 더 낮다면
`.env`의 `KIS_REQUEST_INTERVAL_MS`를 `1000` 이상으로 올리세요.

현재 추천 점수에 쓰이는 애널리스트·기관 수급 신호는 계속 모의 데이터입니다.
화면은 실제 가격과 모의 추천 신호를 구분해서 표시합니다.
